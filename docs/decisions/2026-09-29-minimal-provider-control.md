# 공급자 설정과 하위 에이전트 사용은 사용자 설정을 따르고 Saturn은 추적만 한다

| 항목 | 값 |
|---|---|
| 날짜 | 2026-09-29 |
| 상태 | 채택 |
| 대체 | 없음 |
| 관련 문서 | [아키텍처](../architecture.md), [핵심 규칙 설계](../components/core.md), [엔진 설계](../components/engine.md) |

## 배경

Codex와 Claude는 스스로 하위 에이전트를 띄울 수 있었다(2026-09-29 확인). 하위 에이전트 수, 백그라운드 실행, 샌드박스, 네트워크, 권한은 공급자 설정으로 정해졌다. Saturn이 실행 인자로 이 값을 고정하면 사용자가 공급자에 정한 설정과 달라졌다. 멈춤, 쓰기 잠금, 맥락 정리 경계는 하위 에이전트까지 끝났는지 알아야 판정할 수 있었다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| 사용자 설정 우선, Saturn은 추적만 | 사용자가 정한 공급자 동작 유지, 공급자 기능 추가에 대응 불필요 | 하위 에이전트 추적 구현, 설정으로 증명하지 못한 실행의 자동 재개 불가 |
| 실행 인자로 하위 에이전트와 네트워크 고정 | 예측 가능한 실행 범위, 자동 재개 증명의 단순화 | 사용자 설정 무시, 공급자 기능 제한 |

## 결정

사용자 설정 우선, Saturn은 추적만을 골랐다. 사용자가 고른 공급자 동작의 유지가 기준이었다.

## 결과

- Saturn 기본값은 사용자 설정이 없을 때만 적용
- 하위 에이전트의 시작, 진행, 끝 기록
- 작업 끝을 트리 유휴로 판정
- 판단기 키 보안(환경 변수 제거, 훅)만 예외
- 설정으로 증명하지 못한 실행의 자동 재개 불가
