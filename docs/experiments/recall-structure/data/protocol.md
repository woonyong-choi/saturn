# 수집 전 프로토콜 집계 보정

Codex의 `skip_host_skill_discovery` 시작 경고가 `item.completed`의 `error` 항목으로 전달되었다. 첫 수집기는 응답·추론 이외의 모든 항목을 도구 호출로 세어 두 턴의 시작 경고를 도구 호출로 잘못 집계했다.

원시 이벤트를 대조한 결과 해당 항목은 알려진 CLI 시작 경고였으며 실제 도구 호출이 아니었다. 원응답과 기존 result.json, 최초 실패 판정은 보존한다. 독립 검증 결과에는 기록된 도구 수와 원시 이벤트에서 대조한 실제 도구 수를 함께 남긴다. 알려진 시작 경고만 진단으로 분리하며 다른 오류나 알 수 없는 항목을 숨기지 않는다.

새 응답을 다시 뽑아 성공으로 대체하지 않는다. 같은 원자료의 계측 오류만 바로잡는다. 정식 질문 수집 전 수집기를 수정했고 질문·정답·품질 판정 기준은 바꾸지 않았다. 시작 경고도 원시 자료와 진단 목록에 남긴다.
