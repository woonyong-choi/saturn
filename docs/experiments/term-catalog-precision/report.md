# 용어 카탈로그 짝 정밀도와 묶음 확인 비용: 실험 결과

## 요약

괄호 표기 짝 후보의 정밀도는 1.5%(3/200, 95% 신뢰구간 [0.5, 4.3]), 주석 아래 식별자는 1.0%(2/200, [0.3, 3.6]), 같은 턴 함께 나옴은 0.5%(1/200, [0.1, 2.8])다. H1~H3은 기각이고, Dice, 증거 3번, 가중치 순서 가설(H4~H6)은 보류다. 짝 20개 묶음 요청의 추정 입력 토큰 중앙값은 3,129로 H7은 기각, 짝마다 한 요청보다 44.8% 적어 H8은 채택이며, 지연 가설 H9는 Jev 키가 없어 보류다. 설계에서 코드 표시 앞뒤 모양과 주석 아래 식별자 출처를 빼고, 함께 나옴을 보조 증거로 적고, 묶음 토큰 추정치를 측정값으로 바꿨다.

- 토큰은 judge를 호출하지 않고 요청 본문 JSON의 글자 수로 추정했다.

### 탐색 분석

- 괄호 표기 짝 295개 중 289개가 코드 표시 앞뒤 모양에서만 나왔고, 이 모양의 정밀도는 1.5%(3/199)였다. `한글(식별자)`, `식별자(한글)` 모양 짝은 6개였고 라벨이 있는 3개 중 1개(`정리`와 `compaction`)가 `same`이었다.
- 주석의 모든 한글 단어와 넓힌 정의 키워드로 캐면 주석 짝은 4,937개로 늘고, 새로 생긴 짝의 정밀도는 1.5%(3/200, [0.5, 4.3])였다.
- `unclear` 4행을 빼도 정밀도는 괄호 1.5%, 주석 1.0%, 함께 나옴 0.5%로 같았다.
- 괄호 표기와 주석이 함께 찾은 짝은 0개였다.
- 함께 나옴의 Dice 사분위 구간별 `same`은 아래부터 0/50, 0/50, 0/50, 1/50이었다. 위 두 구간의 Dice는 0.889~1.0이었다.
- 확인 대기 규칙(점수 2.0, 증거 3번)을 통과한 짝은 9개였고 그중 1개가 `same`이었다. 함께 나옴 Dice의 최댓값은 1이라 함께 나옴만으로는 대기에 오르지 못한다.
- 한글 1글자당 토큰을 0.6으로 두면 묶음 중앙값은 2,415, 감소율은 51.2%였다. 1.6으로 두면 4,206, 37.7%였다.

## 논의

### 해석

세 출처 모두 후보 단계 정밀도가 5% 아래라, 지금 규칙으로 캔 짝은 대부분 judge 확인에서 걸러야 할 잡음이다. 코드 표시 앞뒤와 주석 첫 단어는 같은 문장에 있을 뿐 같은 대상을 가리키지 않았고, 함께 나옴은 한 턴에 경로 조각이 많아 우연한 짝이 쌓였다. 정밀도가 모두 바닥에 붙어 출처 사이 순서와 증거 3번 규칙의 효과는 가릴 수 없었으므로 가중치 3은 초안으로 두었다. 묶음 확인은 요청마다 반복되는 공유 부분만 줄이므로 감소율은 짝마다 증거 길이가 길수록 작아진다.

### 타당성 위협

| 종류 | 위협 | 이 실험에서 |
|---|---|---|
| 내적 | 라벨을 붙이는 사람이 실험자 한 명이라 기대에 맞춰 라벨이 기울 수 있다. | 섞인 시트에서 두 말만 보고 판정했다. 결과는 가설과 반대 방향으로 크게 벗어났지만 두 사람 일치도는 재지 못했다. |
| 내적 | 설계 문서 일부를 미리 읽어 괄호 표기 규칙을 그 문서에 맞췄을 수 있다. | 미리 읽은 `term-catalog.md`의 `로그인(login)` 예문이 말뭉치에 들어갔지만 라벨 표본에는 뽑히지 않았다. |
| 구성 | 두 말만 보고 판정하므로 프로젝트 안에서만 통하는 뜻을 놓친다. | `unclear`는 4행이었고, 빼고 세도 정밀도는 같았다. |
| 구성 | 토큰 수를 tokenizer 없이 추정하고, `term` 요청 본문 모양은 설계에 없어 실험이 정했다. | 한글 토큰 비율에 따라 묶음 중앙값이 2,415~4,206으로 움직여 H7 판정은 추정 규칙에 기댄다. H8 판정은 세 비율에서 모두 30%를 넘었다. |
| 구성 | 정밀도는 확인 전 후보의 비율이라 judge 확인 뒤 카탈로그의 정밀도와 다르다. | 결론을 후보 캐기 규칙과 가중치에만 썼다. |
| 외적 | 괄호와 주석 출처를 Saturn 저장소 문서와 코드로 잰다. 실제 카탈로그는 에이전트 답과 도구 결과에서 캔다. | Saturn 문서는 원어를 그대로 쓰는 규칙이라 괄호 번역 표기가 6개뿐이었다. 에이전트 답에서는 이 모양이 더 많을 수 있다. |
| 외적 | `cooc`은 한 사용자의 기록 하나다. | 기록 파일 667개에서 사용자 턴은 1,234개뿐이었다. |
