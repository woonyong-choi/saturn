# 보류된 제약 대체 구간과 간접 지시 정확도: 실험 결과

## 요약

현행 `route@1.1`의 간접 지시 입력 `is_constraint` 정확도는 74.5% [68.0, 80.0](149/200)였고, 앞 입력의 제약 등록 여부를 state에 넣은 `flag`는 현행보다 0.5%p [−3.8, 4.8] 높아 차이가 없었으며, 등록된 원문을 넣은 `flag_text`는 5.5%p [−10.6, −0.5] 낮았다. H5는 보류, H6은 기각이고 두 후보 모두 채택 규칙을 채우지 못한다. 현행 state와 질문을 유지하고, `replaces_<n>` 구간(H2~H4)은 보류다. H1과 H3는 신뢰구간이 기준에 걸렸고, H2와 H4는 신뢰구간 하한이 기준(90%, 70%)을 넘지만 Holm 보정 p값이 0.088, 0.12로 0.05보다 커서 보류이며 후속은 [#186](https://github.com/woonyong-choi/saturn/issues/186)에서 잰다.

## 논의

### 해석

앞 입력의 제약 등록 여부를 state에만 넣는 방식은 간접 지시 입력의 정확도를 올리지 못한다. 등록 판정이 94.7%로 거의 맞는데도 `flag`는 `baseline`과 같고 라벨을 넣은 `oracle_flag`도 1.5%p 높은 데 그쳐, judge는 state의 등록 여부를 거의 쓰지 않는다. `flag_text`는 `indirect-constraint` 정확도를 54.0%로 낮췄고, 질문 문장에 등록 여부 규칙을 더한 `flag_hint`는 간접 지시 입력을 95.5%로 올렸지만 일반 제약 입력의 재현율이 무너져 쓸 수 없으며 이 실험은 그 원인을 가르지 못한다. `replaces_1`은 0.8 이상 구간 정밀도가 96.8%이나 n = 93이라 90% 기준을 보정 후에도 가르지 못했고, 부분 쌍 60개 중 35개가 0.5 미만으로 떨어지는 문제는 #121과 같았다.

### 타당성 위협

| 종류 | 위협 | 이 실험에서 |
|---|---|---|
| 내적 | 문장과 라벨을 같은 사람이 써서 판정이 쉬운 문장으로 기운다. | 새 간접 지시 문장 150건의 `baseline` 정확도(72.7%)가 #121 문장 50건(80.0%)보다 낮아 새 문장이 더 쉬운 쪽으로 기울지 않았다. 라벨과 평가 세트는 수집 전 커밋 `056c173`에 고정됐다. |
| 내적 | judge 답이 같은 입력에서도 실행마다 달라질 수 있다. | 항목과 조건마다 한 번만 물었다. 응답 모델은 모두 `jev-1.13.0`이었고 #121 항목 50건의 `baseline` 정확도는 #121 결과(80.0%)와 같았다. 반복 편차는 재지 않았다. |
| 내적 | 조건 사이 차이가 state 때문이 아니라 요청 순서나 시각 때문일 수 있다. | 모든 조건과 쌍 질문을 시드 152로 섞어 약 10분 안에 물었고 같은 입력의 조건끼리 짝지어 비교했다. |
| 구성 | 등록 여부를 judge의 앞 입력 판정으로 만들어, 앞 입력을 잘못 판정하면 오류가 이어진다. | 등록 판정 정확도는 94.7%였고, 라벨을 넣은 `oracle_flag`도 결과가 같아 등록 판정 오류가 결론을 바꾸지 않았다. |
| 구성 | 실제 엔진은 `is_constraint`를 `route` 질문 세트의 다른 질문과 함께 묻고 `replaces_<n>`을 최대 10쌍 함께 묻는데, 이 실험은 질문 하나씩 묻는다. | 함께 묻는 조건은 재지 않았다. 엔진의 판단 기록으로 judge 학습 채점에서 다시 확인한다. |
| 구성 | 새 state 필드 이름과 값은 이 실험이 정한 문자열이다. | `previous_input_registered_as_constraint`, `registered_constraint`만 재서 다른 이름이나 표현은 재지 않았다. |
| 외적 | 합성 문장은 실제 사용자 입력보다 짧고 규칙적이며, 새 간접 지시 문장은 같은 사람이 쓴 같은 틀이 많다. | 결론은 합성 한국어 입력에만 적용한다. 새 간접 지시 문장은 `아니, ~로 바꿔`, `그거 ~로 바꿔` 틀이 많았다. |

### 한계

- 확인 가설 8개 중 5개가 보류여서 H1~H4의 판정은 구간 폭에 좌우된다. H1의 신뢰구간 상한은 80.0%로 기준 80%에 거의 닿는다.
- `flag_hint`는 탐색 조건이라 보정 없이 보고했고, 질문 문장을 달리 쓴 변형은 재지 않았다.
- 부분 라벨의 정답 구간을 0.5 이상 0.8 미만으로 둔 것은 사전 등록 규칙이다. 부분 충돌을 대체 질문 하나로 잡을 수 있는지는 이 실험이 답하지 않는다.
- 간접 지시 입력은 앞 입력이 바로 앞 턴인 경우만 담았다. 앞 제약이 여러 턴 전에 있는 경우는 재지 않았다.
