# 입력 관계 이진 판단: 개발 실험 설계

| 항목 | 값 |
|---|---|
| 이슈 | [#544](https://github.com/woonyong-choi/saturn/issues/544) |
| 관련 설계 | [router](../../design/router.md), [입력 처리](../../design/input-handling.md) |
| 사전 데이터 | [한국어 이어 가기 결과](../continuation-judgment-korean/report.md)의 608턴과 라벨 분포·기존 B 조건을 열람했다. 같은 표본을 개발 자료로 재사용하며 독립 확인이라고 부르지 않는다. |

## 질문

기존 `keep_current` 한 질문을 독립된 작업 관계 두 질문으로 바꾸면, 실제 대화에서 새 작업을 기존 작업에 잘못 붙이는 일을 줄이면서 이어 가기 처리량을 유지하는가. 작은 질문도 장기 목표와 직전 진행이 포함된 동일한 state를 받는다.

## 가설

| 가설 | 예측 | 적용 범위 |
|---|---|---|
| H1 | 새 작업 오접합이 명확한 새 작업 라벨의 5% 이하이고 Wilson 95% 상한도 10% 이하다. | 기존 개발 표본의 명확 라벨. 독립 확인 목표는 상한 5% |
| H2 | 이어 가기 재현율이 60% 이상이고 Wilson 95% 하한도 60% 이상이다. | 같은 표본의 이어 가기 라벨 |
| H3 | 묻기 비율이 전체 40% 이하이고, 한 번의 Jev 요청으로 두 질문을 받은 토큰 수가 기존 B 요청보다 적다. | 전체 608턴, 사용량 보고가 있는 대응 호출 |

## 설계

| 항목 | 값 |
|---|---|
| 조건 | 기존 B 요청의 첫 Jev 응답과 신규 후보별 `noul` 두 질문을 같은 입력에서 비교한다. |
| 배정 | 기존 표본 608턴을 ID 오름차순으로 고정하고 8개 병렬 통로에서 신규 요청을 보낸다. |
| 눈가림 | 신규 요청은 라벨·기존 Jev 답·후속 사용자 입력을 받지 않는다. 분석기는 수집이 끝난 뒤 라벨을 읽는다. |
| 환경 | 기존 가림 처리된 로컬 표본, Jev 1.13.0, HTTPS와 TLS 검증, Python 표준 라이브러리 |

신규 요청에는 기존 B와 동일한 `chat`, 현재 입력, 직전 입력·목표·진행 발췌를 넣는다. 질문은 각각 “현재 입력이 직전 작업을 완성·수정·확인하는가”와 “직전 작업의 결과 없이 독립된 새 목표를 시작하는가”다. 두 질문은 한 HTTP 요청에 담는다. `P(같은 작업) >= 0.7`이고 `P(독립 작업) <= 0.3`일 때만 이어 가기, 반대면 새 작업, 나머지와 실패는 묻기로 처리한다. 이 경계는 결과 열람 전에 고정한다.

## 변수

| 변수 | 종류 | 정의 | 단위 |
|---|---|---|---|
| `false_join` | 측정 | 새 작업 라벨인데 이어 가기로 보냄 | 건 |
| `continue_recall` | 측정 | 이어 가기 라벨 중 이어 가기로 보냄 | 건·비율 |
| `ask` | 측정 | 묻기 또는 요청 실패 | 건·비율 |
| `tokens` | 측정 | Jev 보고 입력·출력 토큰 합 | 토큰 |
| `elapsed_ms` | 측정 | 요청 시작부터 종료까지의 벽시계 시간 | 밀리초 |

## 표본

| 항목 | 값 |
|---|---|
| 출처 | 기존 한국어 대화 608턴과 독립 두 모델의 합의·재판정 라벨 |
| 크기 | 608턴 전수. 명확한 라벨은 기존 결과에서 587턴 |
| 크기 근거 | 개발 표본 전수. 새 작업 72턴에서 오류 0건의 Wilson 상한은 약 5.1%다. 개발 통과만 10%로 두고 독립 확인에서는 5%를 유지한다. |
| 중단 규칙 | 인증 거절 또는 연속 요청 실패 10회에서 중단한다. 성공·실패를 재전송하지 않는다. |
| 반복과 예열 | 각 턴 한 번, 예열 없음. 기존 B의 첫 반복만 사용한다. |

## 분석

| 가설 | 지표 | 방법 | 채택 기준 |
|---|---|---|---|
| H1 | 오접합 `k/n` | Wilson 양측 95% 구간 | 점추정 <= 5%이고 상한 <= 10% |
| H2 | 이어 가기 `k/n` | Wilson 양측 95% 구간 | 하한 >= 60% |
| H3 | 묻기 `k/608`, 토큰 대응 차이 | Wilson 95%, 세션 군집 bootstrap 3,000회·시드 544202 | 묻기 <= 40%, 토큰 차이의 95% 구간 상한 < 0 |

| 항목 | 규칙 |
|---|---|
| 제외 기준 | 기존 `uncertain` 21턴만 H1·H2에서 제외하고 H3 묻기에 포함한다. |
| 실패한 실행 | 오답 대신 묻기로 처리하며 H3 전체 분모에 포함한다. 사용량 누락은 0으로 대체하지 않는다. |
| 다중 비교 | H1·H2·H3 모두 충족해야 다음 독립 확인 평가를 설계한다. 이 개발 실험으로 운영 채택은 하지 않는다. |

## 판정

| 결과 | 설계에 반영 |
|---|---|
| 채택 | 세 가설을 통과하면 새로운 세션 계열에서 눈가림 라벨을 만든 독립 확인 평가를 #544에 추가한다. |
| 기각 | 오접합·재현율·묻기·토큰 가운데 한 기준의 반대 방향이 명확하면 이 질문 조합을 폐기한다. |
| 보류 | 구간이 넓거나 호출·사용량이 누락되면 현재 기본 질문과 행동을 유지한다. |
