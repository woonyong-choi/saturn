# 지속 제약 등록의 선행 탐색

## 범위

이 기록은 4,000건 수집 전에 같은 대화에서 수행한 400건 탐색을 사후에 보존한다. [원래 작업 범위 실험](../constraint-scope/report.md)의 표본과 모델 합의 라벨을 재사용했다. 독립 확인 표본이나 사람이 직접 확정한 정답으로 취급하지 않는다.

## 관측

실제 Jev 요청은 400회였고 세 질문을 한 요청에 넣었다. 399회가 당시 응답 검증을 통과했다. 원응답 본문은 당시 파일 생성 금지 조건 때문에 보존하지 않았다. 지금 남길 수 있는 근거는 질문, 호출 집계, 입력별 예측 확률, 상태, 지연, 해시다. 원응답을 복원한 것처럼 기록하지 않는다.

[집계](results/pilot-summary.json)에 고정 기준값 결과와 사후 탐색 결과를 보존했다. 자동 0.77·확인 0.43의 한국어 후보는 자동 정밀도 10/11, 자동 재현율 10/44, 확인 후보를 포함한 재현율 37/44, 확인 후보 74/400이었다. 확인 후보에 사용자가 항상 정확히 답한다는 가정이므로 실제 사용자 완료율이 아니다.

## 해석

질문과 기준값을 같은 표본에서 골랐으므로 90.9%를 일반화 성능으로 주장하지 않는다. 4,000건 실험은 이 후보를 고정하고 이전 표본과 같은 세션을 제외한다. 독립 정답을 준비하지 못하면 새 관측의 정확도는 미평가다.

## 자료 보존

질문은 [questions.json](questions.json), 집계는 [pilot-summary.json](results/pilot-summary.json)에 있다. 입력별 예측과 라벨은 Git 제외 실험 공간에 보존한다. API 키와 대화 원문은 공개하지 않는다.
