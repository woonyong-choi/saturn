# 지속 제약 등록의 대화 표본 확대: 실험 설계

| 항목 | 값 |
|---|---|
| 이슈 | [#382](https://github.com/woonyong-choi/saturn/issues/382) |
| 관련 설계 | [제약](../../design/constraints.md), [router](../../design/router.md) |
| 기준 시점 | 2026-10-05 |
| 사전 데이터 | constraint-scope의 400건과 이 대화에서 수행한 추가 호출 400회, 기준값 탐색 결과 |

## 질문

사용자의 실제 대화에서 중복을 제거한 입력 4,000건에 고정한 Jev 질문을 적용한다. 기존 400건에서 고른 한국어 질문과 기준값이 다른 대화에서도 자동 등록 정밀도와 제약 발견율을 유지하는지 확인한다.

## 가설

| 가설 | 예측 | 적용 범위 |
|---|---|---|
| H1 | 한국어 질문의 자동 기준값 0.77에서 정밀도가 90% 이상이다. | 독립 정답이 있는 신규 입력, 자동 예측 양성 100건 이상 |
| H2 | 같은 정책의 자동 재현율이 70% 이상이다. | 독립 정답이 있는 신규 입력 |
| H3 | 확인 하한 0.43에서 자동과 확인 후보의 결합 재현율이 70% 이상이고 확인 비율은 20% 이하이다. | 정답이 있는 신규 입력과 전체 요청; 확인은 사용자가 항상 정답으로 답한다는 가정 |
| H4 | 세 질문을 함께 보낸 요청의 p95 지연이 1초 미만이고 호출·응답 검증 실패율은 1% 이하이다. | 전체 시도; 질문별 독립 지연 해석 금지 |

H2는 사용자 확인 없이 쓸 수 있는지를 따로 검증한다. H3가 통과해도 H2를 통과한 것으로 처리하지 않는다. 이 대화의 400건 탐색에서 한국어 0.77은 10/11 정답, 자동 발견 10/44였다. 확인 하한 0.43의 결합 발견 37/44는 실제 사용자 확인 실험 결과가 아니다.

## 설계

| 항목 | 값 |
|---|---|
| 조건 | 이전 scope 영어 질문, 고정한 한국어 질문, persistent·task_local·no_rule·uncertain의 4분류 질문 |
| 배정 | 시드 38220261005의 해시 순서로 입력 선택; 같은 입력의 세 질문은 한 요청에서 평가 |
| 눈가림 | Jev에 정답, 뒤 대화, 이전 점수, 프로젝트 이름 제공 금지 |
| 환경 | Python 표준 라이브러리, HTTPS 공식 endpoint, jev-1.13.0 고정 |
| 반복 | 주 분석 입력당 1회; 반복 호출로 표본 수 보충 금지 |
| 예열 | 별도 예열 없음; 인증 확인 GET은 추론 수에서 분리 |

정확한 질문은 questions.json에 고정한다. 앞선 실행 스크립트에서 질문 값을 추출해 사람이 다시 입력하면서 문장을 바꾸지 않는다. 각 입력에는 앞선 사용자 입력 최대 다섯 개와 그 사이 assistant 텍스트, 최신 사용자 입력을 제공한다. 숨은 추론, 도구 호출·응답, 설정과 인증 파일은 수집하지 않는다.

## 표본

| 항목 | 값 |
|---|---|
| 출처 | 로컬 Claude·Codex 대화 로그의 사용자 입력; 기존 실험의 출처 정보로 중복 제외 |
| 크기 | 중복 제거 후 신규 입력 4,000건 |
| 크기 근거 | 사용자가 지정한 표본 예산; 정밀도 증명용 예측 양성 수와 별개 |
| 제외 | subagent·exec 자동 세션, 도구 결과·자동 주입 메시지, 비어 있는 입력, 기존 400건과 같은 세션, 동일 입력 상태, state 80,000바이트 초과 |
| 부족할 때 | 확보한 실제 수를 보고하고 부족 상태를 유지; 반복·합성·기준 완화로 표본 보충 금지 |
| 중단 규칙 | 4,000회 완료, 인증 거절, 연속 실패 3회, 관측 입력 비용 USD 3 도달 중 먼저 발생한 조건 |

자료의 출처 파일 수, 후보 수, 제외 사유, 프로젝트·세션 분포와 해시를 API 호출 전에 기록한다. 대화 앱의 user 역할은 사람이 직접 썼다는 인증이 아니므로 붙여넣기와 자동 입력의 잔존 가능성을 한계에 남긴다.

### 정답

정답은 Jev 점수와 별도로 만든다. 같은 입력에 대한 기존 정답을 식별자와 내용 해시로 연결할 수 있을 때만 재사용한다. 제약 정의가 다른 실험의 라벨은 재사용하지 않는다. 새 표본은 두 독립 판정의 합의와 근거 위치를 갖춰야 평가용으로 사용한다. 불일치·근거 부족은 uncertain으로 남기고 다수결을 만들기 위해 같은 모델을 반복 호출하지 않는다. 사용자 판정과 모델 합의 정답은 각각 보고한다.

현재 주어진 인증은 Jev 호출용이다. 독립 라벨러가 실행되거나 새 정답이 준비됐다고 가정하지 않는다. 정답을 확보하지 못해도 처리율·지연·비용 측정은 할 수 있으나 H1~H3의 정확도 부분은 미평가로 남긴다. Jev 자신의 답, 호출 성공, 반복 일치도를 정답으로 삼지 않는다.

## 분석

| 가설 | 지표 | 방법 | 채택 기준 |
|---|---|---|---|
| H1 | 정밀도 | 입력 Wilson 구간과 프로젝트 군집 bootstrap을 함께 보고; 양성 분모 0인 재표집 비율도 보고 | 예측 양성 100건 이상이고 두 구간 하한 모두 90% 이상 |
| H2 | 자동 재현율 | H1과 같은 방법 | 두 구간 하한 모두 70% 이상 |
| H3 | 결합 재현율·확인 비율 | 재현율은 정답 표본, 확인 비율은 전체 시도; 각각 동일 구간 | 재현율 하한 70% 이상, 확인 비율 상한 20% 이하 |
| H4 | p95·실패율 | 입력 bootstrap과 실패 비율 Wilson 구간 | 지연 상한 1초 미만, 실패율 상한 1% 이하 |

네 가설에 가족 오류율 0.05를 나누고, 가설 안 지표 수로 다시 나눈 양측 구간을 쓴다. 군집 bootstrap은 시드 38220261005로 10,000회 수행한다. 프로젝트가 다섯 개 미만이거나 예측 양성 분모가 없는 재표집이 5%를 넘으면 일반화 채택을 보류한다. 표본 내 설명용 95% 구간과 채택용 보정 구간을 구분한다. 입력 수가 커져도 한 사용자의 프로젝트 상관을 독립 표본 수로 부풀리지 않는다.

| 항목 | 규칙 |
|---|---|
| 실패 | 호출 상한에 포함, 재현율에서 놓침, 형식 실패와 HTTP 실패를 분리; 재전송 금지 |
| 판단 불가 | 정밀도·재현율에서 분리하고 자동 등록된 미확정 수와 모두 오답인 민감도 분석을 함께 보고 |
| 추가 탐색 | 다른 기준값·질문 결합은 탐색으로만 기록; H1~H4의 조건 변경 금지 |
| 결측 정답 | 전체 정확도 추정 금지; 라벨 있는 범위의 결과와 미평가 수를 명시 |
| 집계 | k/n, 구간, 질문 버전, 표본 해시, 호출 실패, 토큰을 summary.json에 기록 |

## 호출과 보존

세 질문은 같은 state를 공유하는 한 HTTP 요청이다. 최대 추론 4,000회와 인증 GET 1회를 구분한다. 동시 수는 4, 요청 제한 시간은 30초이며 TLS 검증을 유지하고 redirect를 거부한다. 키는 숨김 입력으로 받아 메모리에만 두고, 요청 헤더·키·인증 설정을 결과에 저장하지 않는다. 알려진 키 패턴, 이메일, 절대 경로를 전송 전에 가린다.

실험 원자료와 요청·응답은 Git에서 제외된 실험 공간에 보존하고 공개 문서에는 집계와 해시만 둔다. 원본 대화는 수정하지 않는다. 실행 전 계획·질문·스크립트·표본의 해시와 UTC 시각을 봉인한다. 사용자의 기존 커밋 금지 지시를 유지하므로 사전 커밋 대신 해시 봉인을 사용하고 이 차이를 보고서에 명시한다. 별도 요청 없이 commit·push·PR·이슈 변경을 하지 않는다.

## 판정

| 결과 | 설계에 반영 |
|---|---|
| 채택 | 고정 후보의 적용 범위를 제안; 제품 기본값 수정 제외 |
| 기각 | 미달 지표와 오류 유형을 기록; 채택을 위한 사후 조건 변경 금지 |
| 보류 | 표본 부족, 정답 부족, 신뢰구간과 군집 한계를 구분해 기록 |

## 타당성 위협

| 종류 | 위협 | 대응 |
|---|---|---|
| 내적 | 다른 질문을 같은 요청에 넣은 영향 | 세 조건의 묶음 실행임을 명시하고 단독 실행 성능 주장 금지 |
| 구성 | 사후 의도와 당시 알 수 있던 정보의 차이 | 정답 근거와 판정 시점, 불확실 라벨을 분리 |
| 구성 | 모델 합의 라벨의 오류 | 사용자 정답과 구분, 근거 없는 합의 제외 |
| 외적 | 한 사용자·특정 프로젝트 편중 | 프로젝트·세션별 분포와 군집 구간을 보고 |
| 통계 | 이미 본 400건에서 질문과 기준값 선택 | 기존 세션을 신규 확인 표본에서 제외 |
| 시간 | 서버 상태와 응답 변동 | 버전 고정, 원응답·지연·실패를 보존 |
