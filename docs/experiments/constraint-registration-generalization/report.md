# 지속 제약 등록의 대화 표본 확대: 실험 결과

## 요약

새 대화 입력 4,000건을 4,000회 호출했다. 최초 검증의 유효 응답은 3,982건이고 검증기 경계 오류를 보정하면 4,000건이다. 이후 대화와 연결한 1,000건에서 Astra 합의 라벨을 만들었다. 이 사후 표본에서 Jev 자동 후보의 정밀도는 확정 라벨 기준 30/53(56.6%)이다. 사람 확인 정답은 아니므로 제품 기준값 채택 근거로 사용하지 않는다.

## 방법

[실험 설계](design.md)와 questions.json을 호출 전에 해시로 봉인했다. 이전 400건이 속한 세션을 제외했다. 원응답과 호출 예약을 비공개 실험 공간에 보존했다.

## 설계와 다른 점

기존 커밋 금지 지시를 유지해 사전 커밋 대신 UTC 시각과 SHA-256 봉인을 사용했다. 최초 4,000건 수집 시점에는 독립 정답이 없어 H1~H3의 정확도 분석을 수행하지 않았다. 뒤의 1,000건 평가는 [사후 설계](retrospective-1000.md)에 따라 별도로 수행했다.

확률 합계의 부동소수점 경계 오류를 수집 중 확인했다. 확률 합계가 십진수로 0.99인 응답도 이진 부동소수점 차이는 0.010000000000000009여서 기존 검증기가 거부했다. 사후 재집계에서 18건을 복구해 유효 응답은 4,000건이다. 이는 정답 여부와 무관한 검증기 수정이다. 원래 실패 표시는 유지하고 원응답 수정이나 재호출은 하지 않았다. [검증기 재집계](results/validation-audit.json)에 보정한 후보 수를 별도로 기록했다. H4 표는 사전에 고정한 검증기로 얻은 결과다.

앞선 [400건 탐색](pilot.md)은 새 4,000건의 성능 근거로 합치지 않았다. 프로젝트 단위는 경로 식별자이며 별도 worktree가 같은 논리 프로젝트에 속할 수 있다.

| 질문 | 자동 기준 | 자동 후보 | 확인 후보 |
|---|---|---|---|
| baseline | 0.9 | 29 | 556 |
| korean | 0.77 | 57 | 297 |
| choice | 0.9 | 63 | 98 |

검증기 오류 보정 후 한국어 질문의 자동 후보는 57건, 확인 후보는 301건이다. 이 개수는 정답 수가 아니다. 4,000건을 호출해도 사전 H1의 자동 예측 양성 최소 100건 조건을 채우지 못했다.

### 지연과 비용

확인된 입력 토큰은 29,540,290개, [공식 단가](https://docs.typesafe.ai/models)의 예상 비용은 USD 1.2407다. usage 없는 요청 0건의 비용은 포함하지 않았다.

## 논의

### 이후 대화 기반 1,000건 사후 평가

원본 세션에 4,000건을 다시 연결했다. 처음 연결에서 빠진 63건 중 58건은 보관된 세션에서, 갱신 중이던 5건은 안정된 원본에서 복구했다. Jev 확률만으로 자동 후보 57건과 확인 후보 301건을 전수 선택하고, 낮은 점수 3,642건 중 해시 순서로 642건을 선택했다. 판정자에게 Jev 점수와 응답을 보여주지 않았다. 판정 전에 고정한 표본·방법과 로컬 원자료는 [데이터 설명](data/README.md)에 기록했다.

첫 Astra 판정 1,000건 중 340건은 앞서 저장된 유효 판정을 재사용하고 660건을 새로 판정했다. 두 번째 독립 판정 1,000건에서 모델 용량 오류가 난 두 묶음 24건은 원오류를 보존하고 재시도했다. 두 판정이 유효 근거를 가진 확정 라벨로 일치한 947건은 합의했고, 나머지 53건에 세 번째 판정을 수행했다. 최종 합의는 983건, 미확정은 17건이다. 저장된 2,053개 판정의 근거 위치 참조 오류는 0건이다.

| Jev 점수층 | 표본 | 제약 | 비제약 | 미확정 |
|---|---:|---:|---:|---:|
| 자동 후보, 0.77 이상 | 57 | 30 | 23 | 4 |
| 확인 후보, 0.43 이상 0.77 미만 | 301 | 84 | 209 | 8 |
| 낮은 점수, 0.43 미만 | 642 | 38 | 599 | 5 |
| 합계 | 1,000 | 152 | 831 | 17 |

자동 후보 정밀도는 확정 라벨 53건 중 30건으로 56.6%다. 미확정 4건을 모두 오답 또는 정답으로 두면 52.6~59.6%다. 기술적인 Wilson 95% 구간은 43.3~69.0%다. 전체 4,000건의 자동 후보는 57건뿐이므로 사전 H1의 최소 100건 조건도 충족하지 못한다.

낮은 점수층 642건을 모집단 3,642건으로 가중하면, 자동 재현율 추정치는 9.1%, 자동과 확인 후보를 합친 재현율은 34.4%다. 프로젝트 단위 bootstrap 95% 구간은 각각 4.4~19.4%, 16.6~73.9%다. 미확정 라벨을 양끝으로 처리한 범위는 각각 8.2~10.2%, 31.8~36.9%다. 확인 후보 비율은 모집단에서 정확히 301/4,000=7.525%다. 가중 재현율은 낮은 점수층의 표본 추정에 의존하며, 단순 1,000건 비율이 아니다. 공개 집계 원본은 [retrospective-1000-summary.json](results/retrospective-1000-summary.json)에 있다.

자동 후보 오답 23건은 작업 한정 지시 18건, 작업 목표 4건, 붙여넣기 내용 채택 1건으로 분류됐다. 이후 대화가 길어 일부를 생략한 사례가 672건이다. 같은 Astra 모델의 반복 판정은 서로 연관된 오류를 공유할 수 있고, 한 사용자의 프로젝트·세션도 독립 표본이 아니다. 이 라벨은 사용자 확인 정답이 아닌 근거 기반 대리 정답지다. 사후에 표본과 분석을 정했고 중간 라벨 분포를 보았으므로 사전 가설의 확인 검정으로 해석하지 않는다.

### 해석

호출 성공과 판단 정답은 다르다. 앞선 400건에서 탐색한 90.9%를 이 표본의 정확도로 옮기지 않는다. 이번 대리 정답지에서는 자동 후보 정밀도와 가중 재현율이 목표에 미치지 못한다. 자동 등록 기준값을 제품 기본값으로 채택하지 않는다.

### 타당성 위협

한 사용자의 대화이며 프로젝트와 세션이 독립이지 않다. 역할 필터를 통과한 붙여넣기·자동 입력이 남을 수 있다. 세 질문을 한 요청에 넣었으므로 개별 질문의 지연이나 비용은 분리 측정하지 않았다. 사람 확인 정답이 없고 사후 의도와 모델 판정이 다를 수 있어 모델 품질 채택은 하지 않는다. 서버 상태와 모델 응답은 같은 버전에서도 달라질 수 있다.

## 재현

sh run.sh verify
