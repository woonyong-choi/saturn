# 빠른 조정의 수렴과 진동: 실험 설계

| 항목 | 값 |
|---|---|
| 이슈 | [#120](https://github.com/woonyong-choi/saturn/issues/120) |
| 관련 설계 | [judge 학습](../../design/router-training.md) |
| 사전 데이터 | 없음. 합성 분포의 모수를 정하려고 기준값별 틀림 비율 곡선만 계산했고, 빠른 조정 시뮬레이션은 실행하지 않았다 |

## 질문

빠른 조정은 틀림 신호에 `폭 × 1/q × (1 − α)`, 놓침 신호에 `폭 × 1/q × α`를 더해 기준값을 옮긴다. 이 규칙이 행동한 판단의 틀림 비율을 목표 α 근처로 모으는지, 기준값이 얼마나 흔들리는지, 사용 방식이 바뀐 뒤 다시 맞추는지를 모의 판단 1만 건으로 잰다.

## 가설

| 가설 | 예측 | 적용 범위 |
|---|---|---|
| H1 | 시작 기준값에서 틀림 비율이 5%인 조건에서 후반 5,000건의 행동 중 틀림 비율은 4.0%~6.0% 안이다. | 행동 신호, 합성 분포, 중심값 0.8 |
| H2 | 후반 5,000건의 행동 중 틀림 비율은 3% 조건에서 3%보다 높고 10% 조건에서 10%보다 낮다. | 행동 신호, 합성 분포, 중심값 0.8 |
| H3 | 세 조건 모두에서 후반 5,000건의 100건 안 기준값 폭은 0.02보다 작다. | 행동 신호, 합성 분포, 중심값 0.8 |
| H4 | 틀림 비율이 3%에서 10%로 바뀐 뒤 2,500건 안에 기준값이 10% 조건의 후반 평균 ±0.01 안에 드는 복제 비율은 80%보다 높다. | 행동 신호, 5,000건째 급변 |

## 설계

| 항목 | 값 |
|---|---|
| 조건 | 신호 출처 2가지(행동 신호, 물은 판단만) × 시작 기준값의 틀림 비율 3가지(3%, 5%, 10%)와 급변 조건 하나(행동 신호, 앞 5,000건 3%, 뒤 5,000건 10%). 기준 조건은 행동 신호 5% |
| 배정 | 복제 번호 r마다 `numpy.random.default_rng([120, r])`로 Jev 확률, 정답, 묻기 난수를 만들고 모든 조건이 같은 난수를 쓴다 |
| 눈가림 | 해당 없음. 판정은 사전 등록한 스크립트가 계산한다 |
| 환경 | macOS, Python 3, numpy. 모델 호출 없음. `env.json`에 실행 때 값을 기록한다 |

시뮬레이션은 `saturn-terminal/core/src/judges/calibration.rs`의 `ThresholdState::observe`, `current`, `ask_probability`를 파이썬으로 옮긴 것이다. `scripts/01-collect.py`는 수집 전에 같은 파일의 단위 테스트와 같은 성질(폭 감소, ±0.05 범위, 100번 멈춤, 급변 재시작, 묻기 상한)을 확인한다.

| 항목 | 값 |
|---|---|
| 질문 | 질문 하나, 중심값 0.8, 최저값 0.5, 최고값 0.95, 목표 틀림 비율 α 0.05 |
| 빠른 조정 | n번째 신호의 폭 `0.01 / √(n + 1)`, 틀림 `+폭 × 1/q × (1 − α)`, 놓침 `−폭 × 1/q × α`, 중심값 ±0.05, 최근 100번이 ±0.01 안이면 멈춤, 틀림 신호 지수 평균(0.2, 0.02) 차이가 0.25를 넘으면 재시작(신호 20개 이후) |
| Jev 확률 p | `0.7 × Beta(5, 1.2) + 0.3 × Beta(1.2, 5)`. judge 기준으로 보정된 확률이다 |
| 실제 정답 | 정답 확률 `σ(logit p − δ)`. 사용자 차이 δ는 기준값 0.8에서 행동한 판단의 틀림 비율이 조건의 틀림 비율이 되도록 이분법으로 정한다 |
| 행동 | 판단 당시 기준값 t에 대해 `p ≥ t`이면 행동한다 |
| 묻기 | q는 `ask_probability(p, t, 지금까지 물은 수, 지금까지 판단 수)`이고, 난수가 q보다 작으면 묻는다 |
| 행동 신호 | 행동했는데 정답이 아니면 틀림, 행동하지 않았는데 정답이면 놓침, 나머지는 미확정. 신호마다 그 판단의 q로 1/q 가중한다 |
| 물은 판단만 | 위 규칙을 물은 판단에만 적용하고 묻지 않은 판단은 미확정으로 둔다 |
| 신호 시점 | 판단 바로 뒤 확정한다 |

## 변수

| 변수 | 종류 | 정의 | 단위 |
|---|---|---|---|
| `condition` | 조작 | 신호 출처와 시작 기준값의 틀림 비율 조합 | 없음 |
| `wrong_rate_before`, `wrong_rate_after` | 조작 | 급변 전, 후 기준값 0.8에서 행동한 판단의 틀림 비율 | 비율 |
| `threshold` | 측정 | 판단 당시 `current()` 값 | 확률 |
| `acted`, `acted_wrong` | 측정 | 100건 묶음의 행동한 판단 수, 그중 정답이 아닌 수 | 건 |
| `wrong_signals`, `missed_signals` | 측정 | 100건 묶음의 틀림, 놓침 신호 수 | 건 |
| `restarts` | 측정 | 100건 묶음에서 급변으로 다시 시작한 수 | 회 |
| `frozen_end` | 측정 | 묶음 끝에서 멈춤 상태인지 | 참, 거짓 |
| `late_wrong_rate` | 파생 | 복제마다 판단 5,001~10,000번의 `acted_wrong` 합 / `acted` 합 | 비율 |
| `late_window_range` | 파생 | 복제마다 판단 5,001~10,000번의 100건 묶음별 기준값 최대 − 최소의 평균 | 확률 |
| `late_threshold_mean` | 파생 | 복제마다 판단 5,001~10,000번 기준값의 평균 | 확률 |
| `reached_within_limit` | 파생 | 급변 조건 복제가 판단 5,001~7,500번 안에 100건 평균 기준값이 행동 신호 10% 조건 `late_threshold_mean` 복제 평균 ±0.01 안에 들었는지 | 참, 거짓 |
| `oracle_threshold_after` | 파생 | 합성 분포에서 행동한 판단의 틀림 비율이 α가 되는 가장 낮은 기준값 | 확률 |
| `balance_threshold_after` | 파생 | 합성 분포에서 틀림 신호 가중합 × (1 − α)와 놓침 신호 가중합 × α가 같아지는 기준값. 묻기 상한은 무시한다 | 확률 |

## 표본

| 항목 | 값 |
|---|---|
| 출처 | `scripts/01-collect.py`가 만드는 합성 판단 |
| 크기 | 조건마다 복제 100개, 복제마다 판단 10,000건 |
| 크기 근거 | 정밀도. 복제 사이 `late_wrong_rate` 표준편차를 0.01로 보면 평균의 95% 신뢰구간 반폭은 1.96 × 0.01 / √100 ≈ 0.002로, H1 동등 범위 ±0.01보다 좁다. H4 비율이 0.9이면 n=100의 Wilson 하한은 0.83이다 |
| 중단 규칙 | 정한 크기를 모두 수집한다. 시뮬레이션이 예외로 멈추면 그 실행 전체를 버리고 원인을 고친 뒤 새 실행 id로 다시 수집한다 |
| 반복과 예열 | 복제 100개. 앞 5,000건은 수렴 구간으로 판정에서 빼고 판단 5,001~10,000번만 판정에 쓴다 |

## 분석

| 가설 | 지표 | 방법 | 채택 기준 |
|---|---|---|---|
| H1 | `late_wrong_rate`(행동 신호 5%) | 복제 평균과 정규 근사 95% 신뢰구간, 동등성 단측 검정 둘(TOST, 경계 4.0%와 6.0%) | Holm 보정 p ≤ 0.05 |
| H2 | `late_wrong_rate`(행동 신호 3%, 10%) | 복제 평균과 정규 근사 95% 신뢰구간, 3%는 3%보다 큰지, 10%는 10%보다 작은지 단측 검정 | 두 조건 모두 Holm 보정 p ≤ 0.05 |
| H3 | `late_window_range`(행동 신호 3%, 5%, 10%) | 복제 평균과 정규 근사 95% 신뢰구간, 0.02보다 작은지 단측 검정 | 세 조건 모두 Holm 보정 p ≤ 0.05 |
| H4 | `reached_within_limit`(급변) | 비율 k/n과 95% Wilson 신뢰구간, 0.8보다 큰지 단측 점수 검정 | Holm 보정 p ≤ 0.05 |

| 항목 | 규칙 |
|---|---|
| 기각 | 한 조건이라도 95% 신뢰구간 전체가 채택 기준의 반대쪽에 있으면 그 가설을 기각한다. H1은 구간이 4.0%~6.0%와 겹치지 않을 때다 |
| 보류 | 채택도 기각도 아니면 보류한다 |
| 비율의 단위 | 같은 복제 안 판단은 기준값 경로를 공유해 독립이 아니다. 그래서 `late_wrong_rate` 판정은 복제를 단위로 한 평균으로 하고, 모든 복제를 합친 k/n과 Wilson 신뢰구간은 함께 보고만 한다 |
| 제외 기준 | 후반 5,000건에 행동한 판단이 없는 복제는 `late_wrong_rate`에서 뺀다 |
| 실패한 실행 | 예외로 멈춘 실행은 흐름 표에 한 행으로 적고 결과에 쓰지 않는다 |
| 다중 비교 | 조건별 판정 7개(H1 1개, H2 2개, H3 3개, H4 1개)의 p값을 Holm-Bonferroni로 보정한다 |

## 판정

| 결과 | 설계에 반영 |
|---|---|
| 채택 | judge 학습 요구사항 표의 #120 행에 보고서를 링크하고 빠른 조정 규칙을 유지한다 |
| 기각 | 기각된 가설이 가리키는 규칙(1/q 가중의 크기, 폭 상수, 급변 판정, 놓침 신호의 범위)을 judge 학습 설계에서 고치거나, 선택지가 남으면 `design` 이슈를 열고 미해결 질문에 링크한다 |
| 보류 | 복제 수를 늘린 재실행 `experiment` 이슈를 연다 |

## 탐색 분석

- 물은 판단만 신호로 쓰는 세 조건의 같은 지표를 행동 신호 조건과 비교한다.
- 조건별 `oracle_threshold_after`, `balance_threshold_after`와 후반 평균 기준값을 비교한다.
- 급변 재시작 수, 마지막 멈춤 비율, 후반 틀림 신호 비율, 묻는 빈도를 본다.

## 타당성 위협

| 종류 | 위협 | 대응 |
|---|---|---|
| 내적 | 파이썬 이식이 `calibration.rs`와 다르게 동작할 수 있다. | 수집 전 단위 테스트와 같은 성질을 확인하고, 상수와 분기 순서를 같은 이름으로 옮긴다. |
| 내적 | 같은 복제 안 판단이 독립이 아니라 판단 단위 신뢰구간이 지나치게 좁다. | 판정은 복제 단위 평균으로 한다. |
| 구성 | 실제 사용자는 틀린 행동을 모두 뒤집지 않고 놓친 행동을 모두 직접 하지 않는다. | 신호 출처를 두 가지로 나눠 극단 두 경우를 본다. 감지 비율의 영향은 한계로 적는다. |
| 구성 | 신호를 판단 바로 뒤 확정해 관찰 시간(다음 입력 3개 또는 10분)의 지연을 빠뜨린다. | 지연은 한계로 적고 판정 범위를 지연 없는 경우로 한정한다. |
| 외적 | 합성 분포 하나와 질문 하나만 쓴다. | 결론의 적용 범위를 이 분포와 중심값 0.8로 한정하고, 실제 판단 기록이 쌓이면 같은 지표를 다시 잰다. |
| 외적 | 느린 조정(`/train`)과 순차 검정 되돌리기를 함께 돌리지 않는다. | 빠른 조정만의 성질로 결론을 한정한다. |
