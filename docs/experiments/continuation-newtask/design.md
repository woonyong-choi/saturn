# 새 작업 표본을 늘린 이어 가기 판단 확인: 실험 설계

| 항목 | 값 |
|---|---|
| 이슈 | [#6](https://github.com/woonyong-choi/saturn/issues/6) |
| 관련 설계 | [router](../../design/router.md), [입력 처리](../../design/input-handling.md) |
| 사전 데이터 | 앞 두 실험의 설계·스크립트·집계·이슈 결정, Codex 파일 1,522개와 5개 파일의 필드 구조만 열람. 이번 입력 내용·라벨·Jev 응답은 미열람 |

## 질문

앞 실험의 탐색 후보 B1·B2 0.50이 새로운 입력에서 오접합 5% 이하와 재현율 60% 이상을 만족하는지 확인한다. 오접합의 95% 구간 상한이 5% 이하인지도 별도로 보고한다.

## 가설

| 가설 | 예측 | 적용 범위 |
|---|---|---|
| H1 | B1 0.50은 오접합 5% 이하이고 재현율 60% 이상이다. | 이번에 선택한 명확 라벨·유효 응답 |
| H2 | B2 0.50은 오접합 5% 이하이고 재현율 60% 이상이다. | H1과 동일 |

앞 실험의 확인 기준값은 0.80이었으나 후속 후보는 0.50이었다. 이번에는 새 자료 수집 전에 0.50을 확인 기준값으로 고정한다. 성능 경계 5%·60%와 다중 비교 보정 방식은 유지한다.

## 설계

| 항목 | 값 |
|---|---|
| 조건 | 앞 실험 B1·B2의 `request_for`를 그대로 호출. 질문·state·형식·모델 변경 없음 |
| 배정 | 시드 608, 출처 비례 무작위 대조 최대 800턴과 나머지 후보 최대 1,200턴. 전체 입력 순서·조건 순서를 무작위화 |
| 눈가림 | 라벨러는 다른 최초 라벨·거르기 여부·Jev 응답을 보지 않는다. Jev 수집기는 라벨 파일을 읽지 않는다 |
| 환경 | Python 표준 라이브러리, Jev `jev-1.13.0`, 공식 `codex exec` 0.158.0, `gpt-6-astra`·`gpt-5.6-luna`, reasoning low. Claude 모델 호출 없음, LLM 난수 고정 불가 |

### 원자료와 추출

Claude는 앞 실험의 추출·가림 함수를 사용한다. 기존 608개 ID·프로젝트 UUID를 제외한다. 앞 후속 실험의 worktree가 정리되어 추가 1턴의 비공개 식별자를 찾을 수 없으므로, 겹침을 피하기 위해 2026-10-04까지의 Claude 턴도 제외한다. 이로 인해 Claude 새 표본이 없을 수 있으며 출처 차이를 추정할 수 없으면 그대로 보고한다.

Codex는 `~/.codex/sessions/**/*.jsonl`만 읽는다. 설정·인증 파일을 직접 열지 않는다. CLI 자체 인증 사용은 공식 `codex exec` 실행에만 맡긴다. `session_meta`의 부모 세션 또는 subagent 출처가 있으면 파일을 제외한다. `response_item/message/role=user`의 input_text만 사용자 입력으로 채택하며, event_msg의 중복 사용자 이벤트·developer·system·agent_message·tool 내용은 입력에서 제외한다. 명시적 AGENTS·환경·권한·skill·중단·시스템 요약 접두와 앞 실험의 자동 주입 표식을 제외한다. 자동 접두 목록은 수집 스크립트에 봉인한다. compaction에서 이전 쌍을 끊고 그 뒤 첫 턴은 제외한다. 한글 없는 새 입력과 직전 입력 없는 첫 턴을 제외한다.

직전 사용자 입력 전체, 목표 첫 2,000자, 이후 assistant text 마지막 3블록의 끝 6,000자를 사용한다. Codex assistant의 final phase 또는 task_complete로 idle을 복원하고 나머지는 running으로 둔다. thinking·도구 인자·도구 결과를 쓰지 않는다. 동일 입력 쌍의 해시와 UUID로 복제·fork 중복을 제외하며 세션을 연결하지 않는다. 파일 읽기 전후 해시가 다르면 제외한다. 원본 해시·줄 번호·제외 사유는 비공개 목록에 보관한다.

### 1차 거르기와 비례 표본

거르기는 정답 라벨이 아니다. idle이고 새 입력이 30자 이상인 턴 중, 직전·새 입력의 한글 bigram 및 영숫자 토큰 Jaccard가 0.12 이하이거나 새 입력에 `별도|다른 주제|새(?:로운)? 작업|다음 작업|이제는|이번에는`이 있으면 후보로 둔다. 완료 여부와 어휘 변화로 후보를 찾지만 같은 작업의 새로운 요구도 들어갈 수 있다.

먼저 적격 전체에서 출처 인원수 비례 최대 800턴을 비복원 무작위 추출한다. 라벨 비율을 보고 계속 턴을 골라 넣지 않고 이 대조 표본에 있는 continue를 비례 표본으로 유지한다. 그 다음 미선택 후보에서 출처 비례 최대 1,200턴을 추출한다. 두 집합은 겹치지 않는다. 후보가 부족하면 있는 후보만 사용하며 비후보로 보충하지 않는다. 거르지 않은 대조와 후보 보강의 new·continue·uncertain 비율, 합의율, 오접합·재현율·정밀도를 비교한다. 대조 안에서도 후보/비후보를 비교한다. 보강 표본의 비가중 정밀도를 원래 모집단 정밀도로 해석하지 않는다.

### 라벨과 호출

앞 실험의 판정 질문·창작 예시·15개 묶음·독립 두 지시·JSON schema·최초 라벨 보존·불일치 및 uncertain의 astra 재판정·JSON 수리 최대 한 번을 그대로 재사용한다. 기존 공식 CLI 명령의 `--ignore-user-config`, `--ephemeral`, read-only, 도구·검색 비활성도 유지한다. 모델별 최대 4개 묶음을 동시에 실행하며 같은 최초 라벨러끼리 답을 공유하지 않는다. 두 최초 라벨 단계 완료 뒤 재판정한다. 호출 상한에서 미완료는 uncertain이며 성공한 사례는 버리지 않는다. 인증·모델 거절이면 대체 모델 없이 해당 수집을 중단한다.

Jev는 입력마다 B1·B2 각 한 번만 호출한다. 최대 동시 6회이며 반복·예열은 없다. compact UTF-8 JSON 100,000바이트를 넘으면 미전송 실패로 보존한다. 기본 TLS 검증·HTTPS·redirect 거절·실제 모델명·질문 집합·유한 확률·합 검사를 앞 실험대로 유지한다. 키는 키체인에서 `SATURN_JUDGE_KEY` 프로세스 환경으로만 받고 출력·로그·파일에 쓰지 않는다. 키 일치 문자열을 가리고 라벨러 자식 환경에서 키를 제거한다.

### 판정과 저장

B1은 `p>=t`이면 continue, `p<0.30`이면 new, 나머지는 ask다. B2는 `p>=t`와 `q<round(1-t,2)`이면 continue, `p<0.30`과 `q>=0.70`이면 new, 나머지는 ask다. 실패는 ask이며 정확도 분모에서 제외하되 운영 재현율에는 포함한다. t는 0.50부터 0.95까지 0.05 간격이다. uncertain은 정확도 분모에서 제외하고 묻기 분모에는 포함한다.

원문·라벨·응답·호출 장부·일시 파일은 지정 worktree의 `.local/experiments/continuation-newtask/`에만 보관한다. 원기록·기존 비공개 자료는 읽기만 하고 사본을 만들지 않는다. `/tmp`, `/private/tmp`, `~/.cache`, `mktemp`를 사용하지 않으며 TMPDIR·XDG_CACHE_HOME을 비공개 runtime 아래로 지정한다. 호출 직전 잠금·fsync 예약 장부를 쓰고 실패·수리·미완료도 센다. 예약 후 응답 없는 호출은 재호출하지 않는다.

## 표본

| 항목 | 값 |
|---|---|
| 출처 | 위 두 glob의 아직 쓰지 않은 한국어 사용자 입력 쌍 |
| 크기 | 새 명확 new 목표 363턴, 전체 최대 2,000턴. 기존 new 72는 별도 합산 |
| 크기 근거 | 귀무 p=0.05, 대립 p=0.02, 단측 α=0.0125, power 0.80의 exact binomial 최소 n=363, k=9, power=0.8051. 아래 계산을 스크립트로 재생성 |
| 중단 규칙 | 미리 뽑은 유한 표본 전부 처리 또는 Jev 4,000회·Codex 500회 상한. 성능 결과를 보고 조기 중단하지 않음. 목표보다 부족해도 실제 수만 분석 |
| 반복과 예열 | 각 조건 한 번, 예열 없음. 최대 2,000×2=4,000 Jev. 최초 라벨 최대 134×2=268회, 불일치 최대 134회와 수리를 합쳐 500회 이내 |

`P(X<=k;n,0.05)<=0.0125`를 만족하는 최대 k에서 `P(X<=k;n,0.02)>=0.80`인 최소 n을 탐색한다. 앞 실험 72건을 합산하면 필요한 추가 수는 291건이지만 독립 새 자료 목표는 보수적으로 363건으로 둔다. 363건은 실제 오접합이 2%일 때의 요구이며, 실제 비율이 4.2%에 가까우면 충분하지 않을 수 있다. 독립 이항 가정은 군집 상관과 표본 보강을 보정하지 않는다. 따라서 목표 달성 자체를 구간 통과로 해석하지 않는다. 구간 계산 근거는 [NIST 비율 구간과 이항 역산](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)이다.

## 분석

| 가설 | 지표 | 방법 | 채택 기준 |
|---|---|---|---|
| H1 | B1 0.50 오접합·재현율 | 단측 98.75% Clopper–Pearson 경계, 출처 내 세션 cluster bootstrap 2,000회 명목 95% | 오접합 exact·cluster 상한 모두 <=5%, 재현율 exact·cluster 하한 모두 >=60% |
| H2 | B2 0.50 오접합·재현율 | H1과 동일 | H1과 동일 |

두 조건·두 경계의 Bonferroni 보정을 유지한다. 두 방식 모두 오접합 하한>5% 또는 재현율 상한<60%이면 기각, 나머지는 보류다. 별도 보조 판정으로 점추정 5%·60% 충족 여부, Wilson 양측 95% 오접합 상한<=5% 여부를 명시한다. 이 결과를 다중 비교를 통과한 확인 채택과 혼동하지 않는다. 무작위 대조가 더 나쁜 결과이면 보강 전체의 채택만으로 모집단 통과를 주장하지 않는다.

| 항목 | 규칙 |
|---|---|
| 제외 기준 | 첫 턴·비한국어·자동 주입·하위 세션·중복·compaction 경계·변경 파일·기존 사용·보수적 겹침 방지의 수를 기록 |
| 실패한 실행 | 원인을 흐름에 보존, 실패를 정상 new 정답으로 셈하지 않음. 유효 조건부와 운영 재현율 병기 |
| 대응 비교 | 양쪽 유효한 같은 턴, B1/B2 예측 불일치 b/c와 지표 차이, 세션 대응 bootstrap 95% 구간 |
| 다중 비교 | 확인 H1·H2 네 경계 α/4, 그 밖의 곡선·출처·거르기 비교는 탐색 |
| 합산 | 앞 실험 608턴 첫 반복 공개 집계의 TP·FP·FN·TN·ask 분자/분모에 새 표본을 더함. 추가 1턴은 제외. 과거 비공개 B1/B2 응답이 없으므로 합산 군집·개별 대응 분석은 불가. 합산은 개발 자료 포함 기술 통계로 한정 |
| 구간 | 모든 곡선에 k/n·Wilson 95%, 새 표본 주요 지표에 cluster 95%, 0.50 확인에 exact 보정 경계. 출처가 하나면 다른 출처 차이는 미확인 |
| 정밀도와 분포 | 무작위 대조의 정밀도를 비례 표본 추정으로 사용, 보강·합산의 비가중 정밀도는 각각의 혼합 비율에 조건부. new 비율 차이에 세션 bootstrap 95% 제공 |
| 유효 숫자 | 비율 0.1%, 차이 0.1%p, JSON은 계산 정밀도 유지 |

## 판정

| 결과 | 설계에 반영 |
|---|---|
| 확인 기준 충족 | 새 자료·대조·출처 제한을 포함한 근거를 보고서에만 기록 |
