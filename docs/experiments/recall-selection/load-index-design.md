# 검색 자료 재사용 뒤 복원 시간: 측정 설계

## 질문

첫 부하 측정에서 질문마다 원문을 다시 토큰화하는 비용으로 현재 후보가 이전 복원보다 느렸다. 같은 후보 목록의 단어 빈도와 문서 빈도를 한 번 계산해 여러 질문에 재사용한다.

## 설계

선택 규칙과 BM25 식을 바꾸지 않는다. 고정한 실제 질의의 패킷·복원 입력이 수집 입력과 바이트 단위로 같은지 먼저 대조한다. 차이가 나면 같은 동작의 성능 개선으로 보고하지 않고 원인을 확인한다.

입력·크기·반복·시간 범위는 [첫 부하 설계](load-design.md)와 같다. `load-index` 경로에 새 측정 자료를 저장하고 이전 결과를 덮어쓰지 않는다. 비교 대상은 같은 기존 복원 바이너리와 검색 자료를 재사용하는 현재 바이너리다. 시간 수치는 프로세스 시작과 파일 입출력을 포함한 이 환경의 관측값이며 실사용 지연의 상한 보장이 아니다.
