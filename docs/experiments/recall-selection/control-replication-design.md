# 반복 실패의 대조군 비교: 추가 설계

## 질문

후보 반복에서 Claude가 경로 문항에 `unknown`을 답했다. 해당 경로는 전송된 패킷과 복원 원문에 모두 있었다. 후보만 반복해서는 압축에 따른 품질 차이와 모델의 응답 변동을 구분할 수 없으므로 원문 전체와 기존 복원도 같은 횟수로 반복한다.

## 설계

`explicit`의 원문 전체·기존 복원 입력을 각각 두 번 더 실제 호출한다. 같은 18조건과 두 provider이므로 추가 144실행이다. 질문·정답·입력·모델 옵션을 바꾸지 않는다. 실패한 문항만 고르지 않고 모든 조건을 반복한다. 시드는 7112이며 provider마다 직렬로 실행한다.

원문 전체·기존 복원·새 복원은 각각 최초와 추가 두 번을 합쳐 provider당 같은 문항 수로 비교한다. 실행 시점이 다르고 후보 실패를 본 뒤 추가한 분석이므로 탐색 분석이다. 반복을 독립 질문으로 세지 않는다. 엄격 정답 수, 대응한 정답→오답과 오답→정답, 입력 토큰 합계, 실패 원응답을 비교한다.

이 추가 비교로 후보의 실패를 성공으로 바꾸거나 앞 채택 기준을 소급 수정하지 않는다. 전 문항 무손실 기준과 대조군 대비 관측 성능을 구분해 보고한다. 앞 단계의 실패와 입력이 모두 남는다.
