# 질문 수에 따른 복원 종료: 후속 실험 설계

## 질문

복수 질문 배분의 Codex 비교는 104/104로 근거 누락을 회복했지만 입력 토큰 감소 기준을 충족하지 않았다. 질문별 상위 근거를 선택한 뒤에도 전체 질의의 후보로 남은 예산을 채우는 부분을 줄인다.

## 설계

코드 주변 조건 보존을 포함한 후보에서 명시적 질문의 개수로 선택 종료를 정한다. 물음표가 있는 줄이 두 개 이상이면 각 질문의 상위 두 후보만 합치고 전체 질의로 추가 후보를 채우지 않는다. 물음표가 하나인 단일 질문은 전체 질의 상위 세 후보까지만 둔다. 한 줄에 물음표가 여러 개인 입력이나 물음표가 없는 입력은 기존 상대 점수 규칙을 유지한다. 이 규칙은 질문 난이도를 안다는 뜻이 아니다.

`focused` 폴더에서 같은 18조건을 재생한다. 원문 전체와 기존 복원의 대조군은 `coverage`에서 가져온다. 입력 문자열이 같은 새 복원도 성공 여부와 무관하게 재사용하고, 달라진 새 복원 입력은 두 provider에서 다시 호출한다. 새 독립 확인 분석이 아니라 탐색적 개선과 회귀 검증이다. 새 평가 자료를 보았으므로 최초 문서 평가를 미관측 검증으로 부르지 않는다.

두 provider에서 기존 정답 손실이 없고 원문 전체가 맞힌 문항을 모두 회수하며 입력 토큰이 감소하면 동일한 새 복원 입력을 두 번 더 실제 호출한다. 반복 실패도 분모와 원응답에 남긴다. 코드 주변 조건 보존 단계는 이 후보에 포함하고 별도 모델 호출을 하지 않는다. 단계별 고유 호출 수와 입력 재사용 수는 구분한다.

정답표, 질문, 문자 예산, 상대 점수 기준, provider 실행 옵션은 그대로다. 정상 router와 실제 코딩 작업의 성공률은 이 실험의 판정 범위 밖이다.
