# 화면

## 배치

```text
┌────────────────────────────────────────────────────────────────┐
│ 대화 기록                                                      │
│ > [A] 로그인할 때 세션이 바로 끊기는 버그 고쳐                 │
│ > [B] README 오타도 고쳐                                       │
│ [B] claude · 8초 · Token 412                                   │
│ [A] 맥락 정리 후 이어서 진행                                   │
└────────────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────────────┐
│ 작업별 출력 칸                                                 │
│ [A] 출력 중인 작업의 최근 줄                                   │
└────────────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────────────┐
│ 상태판                                                         │
│ ⠙ [A] 작업 중                                                  │
│ ⠹ [D] 판단 중 · 배포 스크립트 정리                             │
│ · [C] 대기 · A 다음 · 테스트도 같이 돌려줘  [보내기] [취소]    │
│ ‖ [E] 보류 · codex · /continue E            [이어서] [취소]    │
│ 자동 판단 일시 중단                                            │
└────────────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────────────┐
│ 팝업                                                           │
│ › help        도움말                               Saturn      │
└────────────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────────────┐
│ 입력창                                                         │
│ ›                                                              │
└────────────────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────────────────┐
│ 바닥줄                                                         │
│ /help 도움말 · Ctrl+C 멈춤                 맥락 38K/200K       │
└────────────────────────────────────────────────────────────────┘
```

## 영역

| 영역 | 보이는 것 | 갱신 시점 |
|---|---|---|
| 대화 기록 | 입력 에코 `> [A] 원문`, 도구 셀, 결과 줄, 맥락 정리와 공급자 전환 한 줄, 피드백 질문, 이번 요청 합계 | 판단 확정, 작업 종료, 다시 실행할 때 기록 저장소에서 최근 부분부터 로드, 위로 스크롤할 때 이전 부분 로드 |
| 작업별 출력 칸 | 출력이 흐르는 작업마다 최근 줄, 높이 상한 8줄, 화면이 작으면 상한 축소 | 완성된 줄 단위 갱신, 출력 시작 때 한 번 이동, 작업 종료 때 전체 내용을 대화 기록으로 옮기고 삭제 |
| 상태판 | 실행 줄, 판단 줄, 학습 줄, 대기 줄, 보류 줄, 알림 줄 순서, 같은 종류 안은 접수 순서 | 엔진 상태 변경, 줄이 생기고 사라져도 다른 줄의 상대 위치 유지, 보류 줄 외에는 종료 때 삭제 |
| 팝업 | `/` 명령 목록과 값 목록, `@` 파일 목록, `$` 스킬 목록, 명령 목록 최대 8행과 오른쪽 출처 표시 | 글자 입력마다 목록 필터 |
| 입력창 | `›` 접두 초안, 붙여넣은 내용 요소 | 키 입력 |
| 바닥줄 | 키 안내, 맥락 크기 | 상태 변경, 턴마다 맥락 크기 |
| 시작 화면 | 로고, Saturn 버전, 공급자 버전, 판단기와 판단기 버전, 폴더 | 실행 때, 첫 결과가 오면 대화 기록 맨 위 머리 셀로 전환 |
| 판단기 키 입력 창 | 판단기 확인 실패 원인, 가린 키 입력칸 | 시작 때 판단기 확인 실패 |
| 폴더 설정 신뢰 창 | 폴더 설정 파일 경로, 지문, 적용되는 항목, 무시되는 항목, 바뀐 줄 | 처음 보거나 내용이 바뀐 폴더 설정을 만난 때, 실행 중이면 다음 입력 접수 전 |
| 보류 재개 질문 | 보류된 작업 목록, 선택지 `모두 이어서`, `골라서 이어서`, `그대로 두기` | 보류 작업이 있는 채팅을 다시 열 때 한 번 |
| 허가 요청 창 | 작업 이름표와 공급자가 붙은 제목, 요청 내용, 이유, 선택지 네 개, 허가를 기다리는 다른 작업 수 | 허가 요청 도착, 1초 입력 보호 뒤 접수 순서로 하나씩, 다른 클라이언트가 먼저 답하면 삭제 |
| 작업 목록 화면 | 필터 전체, 확인 필요, 실행 중, 대기, 보류, 끝남, 묶음 채팅, 폴더, 상태, 작업과 그 아래 하위 에이전트와 자식 채팅, 작업 상세 | `/tasks` 실행, 엔진 상태 변경 때 선택 유지 |
| 전체 기록 | 도구 셀 전체와 줄인 셀을 펼친 대화 기록 | `Ctrl+T` 입력 |
| 사용량 화면 | 에이전트별 새 입력, 캐시 읽기, 캐시 쓰기, 출력, 추론, 판단기 호출과 예상 비용, 맥락 정리, 채점 | `/usage` 실행, 범위 `chat`, `today`, `week`, `all` 선택 |
| 판단기 버전 화면 | 판단기 버전 목록, 버전별 판단기와 보정값과 ECE, 질문별 목표 틀림 비율과 기준값과 최근 200건 틀림과 판단 수 | `/judge version` 실행 |
| 학습 확인 창 | 채점 후보 수, 채점 모델, 예상 토큰, 기준값 조정 대상, 모델 추가 학습 여부 | 실행 조건을 채운 `/train` 실행 |

## 상태 표시

| 표시 | 뜻 |
|---|---|
| `[A]` | 작업 이름표, 살아 있는 작업이 둘 이상이거나 대기·보류 줄이 있을 때만 표시, 끝난 작업의 글자는 비어 있는 가장 앞 글자로 재사용 |
| `> [A] 원문` | 판단이 끝난 입력의 에코, 끼워 넣은 입력은 합쳐진 작업의 이름표 |
| `⠙ [A] 작업 중` | 출력이 아직 없는 실행 중 작업 |
| `⠙ [A] claude · opus · 1분 · 하위 에이전트 2개 실행 중` | 공급자 하위 에이전트가 도는 작업, 하위 에이전트는 이름표 없이 흐리게 접어 표시 |
| `생각 중` | 실행 줄의 하는 일, 공급자가 생각하는 중 |
| `파일 읽는 중` | 실행 줄의 하는 일, 파일 조회 |
| `파일 수정 중` | 실행 줄의 하는 일, 파일 수정 |
| `명령 실행 중` | 실행 줄의 하는 일, 명령 실행과 명령 앞 40칸 |
| `허가 기다림` | 실행 줄의 하는 일, 허가 응답 대기와 경과 시간 정지 |
| `맥락 정리 중` | 실행 줄의 하는 일, 맥락 정리 |
| `공급자 전환 중` | 실행 줄의 하는 일, 공급자 전환 |
| `Token -` | 사용량 보고 전 |
| `⠹ [D] 판단 중` | 판단기가 입력을 판단하는 중, 판단 방식과 관계없이 같은 문구, 근거와 확률 표시 없음 |
| `⠼ [학습]` | `/train` 진행, 단계와 채점 건수와 경과와 토큰 |
| `· [C] 대기 · A 다음` | 실행 중인 작업 A 뒤에 보낼 입력 |
| `· [C] 대기 · 판단 차례` | 같은 채팅의 앞 입력 판단을 기다리는 입력, `[보내기]` 없이 `[취소]`만 표시 |
| `· [C] 대기 · 판단기 연결 기다림` | 판단기 연결을 기다리는 입력 |
| `· [C] 대기 · 쓰기 차례` | 다른 에이전트의 쓰기가 끝나기를 기다리는 입력 |
| `· [C] 대기 · 맥락 정리 뒤` | 세션 교체가 끝나기를 기다리는 입력 |
| `· [C] 대기 · 모든 작업 뒤` | 모든 작업이 끝난 뒤 실행할 세션 변경 명령 |
| `[보내기] [취소]` | 대기 줄 버튼, `/send`, `/cancel`과 같은 동작, 전체 화면 방식에서 클릭 가능 |
| `‖ [A] 보류` | 멈춘 작업이나 보내지 않은 입력, `/continue`로 재개 |
| `[이어서] [취소]` | 보류 줄 버튼, `/continue`, `/cancel`과 같은 동작, 전체 화면 방식에서 클릭 가능 |
| `‖ 멈춤 · [A] [C] 보류됨 · /continue 로 이어서` | 중지 결과, 멈춘 작업과 보내지 않은 입력의 보류 |
| `멈춤 확인 안 됨 · N개 남음` | 공급자 프로세스 묶음 밖에 남은 프로세스 N개 |
| `‖ [E] 보류를 닫을까요?` | 보류 닫기 확인, 보내지 않은 입력 취소, 수정된 파일 유지 |
| `[E] 보류를 닫았습니다` | 보류 종료 완료 |
| `자동 판단 일시 중단` | 판단기 호출 일시 실패, 질문별 대체 규칙 적용 |
