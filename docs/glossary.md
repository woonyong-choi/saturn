# 용어

이 문서의 용어를 코드, 화면, 문서에서 같은 뜻으로 쓴다.

| 용어 | 뜻 | 코드 이름 | 쓰지 않는 말 |
|---|---|---|---|
| 공급자 | Codex, Claude 같은 코딩 에이전트 제품이다. | `provider` | 벤더 |
| 권한 | 에이전트가 할 수 있는 범위다. | `permission` | 권한 모드, 샌드박스 |
| 기록 번호 | 채팅 트리 전체 기록에 매긴 하나의 연속 번호다. | `ledger seq` | 워터마크 |
| 기준 판단기 | 외부 판단 API로 제공되는 판단기다. | `reference` | 없음 |
| 기준값 | 판단 확률로 행동을 가르는 값이다. | `threshold` | 임계치 |
| 끼워 넣기 | 진행 중인 턴에 입력을 추가하는 처리다. | `steer` | 인터럽트 입력 |
| 대기 | 보내기 전 채팅 대기열에 있는 입력 상태다. | `queued` | 없음 |
| 맥락 정리 | 공급자 압축이나 새 세션 재시작으로 맥락 크기를 줄이는 처리다. | `compaction` | 없음 |
| 멈춤 신호 | 진행 중인 처리를 멈추라는 요청이다. | `interrupt` | 없음 |
| 메인 에이전트 | 채팅마다 하나인 주 에이전트다. | `main` | 없음 |
| 보류 | 사용자가 멈춘 작업과 그때 보내지 않은 입력의 상태다. | `held` | 일시정지 |
| 사용량 보고 | 공급자가 보낸 사용량 한 건이다. | `usage report` | 없음 |
| 서브 에이전트 | 판단기가 무관한 작업으로 판단해 채팅에 따로 띄운 에이전트다. | `sub` | 없음 |
| 세션 | 공급자의 실제 대화 하나다. | `session` | 스레드 |
| 스킬 | 공급자에게 전달하는 설명서 폴더 기능이다. | `skill` | 커스텀 명령 |
| 에이전트 | Saturn이 띄운 공급자 프로세스와 그 세션이다. | `agent` | 없음 |
| 엔진 | 공급자 연결, 대기열, 판단기, 기록을 맡는 상주 프로세스다. | `engine` | 데몬, 서버 |
| 이벤트 | 처리 중 나오는 조각인 글, 도구 호출, 결과다. | `event` | 아이템, 델타 |
| 입력 | 사용자가 보낸 입력 하나다. | `input` | 메시지 |
| 작업 | 채팅 안의 작업 하나, 화면 이름표 A, B, C다. | `task` | 없음 |
| 질문 세트 | 판단기에 한 번에 묻는 질문 묶음과 그 버전이다. | `question set` | 없음 |
| 채점 | 판단 기록에 학습용 라벨을 붙이는 처리다. | `labeling` | 없음 |
| 채팅 | 사용자가 보는 대화 하나다. | `chat` | 스레드 |
| 턴 | 입력 하나에 대한 공급자의 한 번 처리다. | `turn` | 없음 |
| 트리 유휴 | 에이전트와 모든 하위 에이전트가 끝난 상태다. | `tree idle` | 없음 |
| 판단 방식 | 행동을 결정하는 판단기를 고르는 설정이다. | `method` | 판단 모드 |
| 판단기 | 입력마다 뜻을 확률로 판단하는 작은 모델이다. | `judge` | 라우터 |
| 패킷 | 새 세션에 넘기는 맥락 묶음이다. | `packet` | 인수 요약 |
| 하위 에이전트 | 공급자가 스스로 띄운 하위 에이전트다. | `subagent` | 자식 스레드 |
| 화면 | 엔진에 붙어 상태를 보여 주고 입력을 받는 클라이언트다. | `tui` | 없음 |
| 효과 범위 | 크래시 뒤 자동 재개 가능 여부를 가르는 실행 기록 값이다. | `effect_scope` | 없음 |
| Saturn 모델 | 판단 기록으로 학습한 로컬 판단 모델이다. | `student` | 없음 |
